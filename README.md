# Mi Launcher

Launcher Android minimalista oscuro y personalizable (Kotlin + Jetpack Compose). Android 8.0 o superior.

## Qué trae
- **Inicio:** reloj grande con fecha (tocar = alarmas) y tus apps fijadas.
- **Cajón de apps:** buscador sin tildes (escribe "camara" y encuentra "Cámara"), lista o cuadrícula de 2 a 5 columnas.
- **Mantén presionada una app:** fijar en inicio, renombrar, ocultar, información, desinstalar.
- **Personalizar** (mantén presionado el fondo de inicio): color de acento, oscurecer fondo de pantalla, fuente, alineación, tamaño de texto, tamaño del reloj, 12/24 h, íconos sí/no y su tamaño, columnas, orden de favoritos, apps ocultas.
- **Gestos:** deslizar arriba = apps · deslizar abajo = notificaciones · botón Inicio = volver.

## Obtener el APK
Cada vez que se sube un cambio a la rama `main`, GitHub Actions compila el APK y lo publica en **Releases**.
1. Abre el repositorio en el navegador del celular → **Releases** → descarga `MiLauncher-v1.0.X.apk`.
2. Ábrelo y permite "instalar apps desconocidas" para tu navegador.
3. Abre Mi Launcher → mantén presionado el fondo → **Usar como launcher predeterminado**.

Las actualizaciones se instalan encima sin perder tus ajustes.
